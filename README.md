# 阅卷 · 申论 / 综应 / 遴选 智能阅卷工作台

> 踩点给分 · 范式切换 · 防幻觉强约束

一个**纯静态单页应用**：填入题干、给定材料与考生作答，工具按对应考试的官方阅卷规则完成校验，并生成一份**结构化阅卷指令**——可直接粘贴给任意 AI 完成按规则批改。

**在线访问：** https://wsh0411.github.io/yuejuan/

无需安装、无需联网依赖（零 CDN / 零 npm / 零外部字体图片），双击 `index.html` 即可离线运行。

---

## 功能

| 模块 | 说明 |
| --- | --- |
| **25 种考试范式** | 国考三档 / 省考联考 / 江苏 ABC / 广东县乡 / 浙江 ABC / 山东 / 北京 / 上海 / 四川 / 普通·定向选调生 / 乡镇公务员 / 综应 ABC / 遴选 / 其他自主命题 / 自动识别 |
| **范式提示条** | 顶部常驻「当前生效阅卷范式 + 阅卷导向」；自动识别给出提醒；综应 B / C 自动弹出专属提示 |
| **9 种题型** | 归纳概括 / 提出对策 / 综合分析 / 公文写作 / 大作文议论文 + 4 种特色题型（校阅改错、论证评价、科技实务、提纲类作答） |
| **实时字数校验** | 按考试差异化容错（常规 10%，乡镇卷 / 广东乡镇 / 遴选 5%），三态着色：达标 / 接近边界 / 超限·不足 |
| **字数要求解析** | 支持「不超过 N 字 / 不少于 N 字 / N 字左右 / A-B 字 / A~B 字 / A—B 字（含全角）/ 纯数字」 |
| **防幻觉拦截** | 题干或给定材料缺失时**拒绝生成**并红框高亮空字段，不强行批改 |
| **指令组装** | 完整角色说明书 + 本次阅卷任务卡（范式 / 题型专项规则 / 满分 / 字数 / 原文）+ 七段固定输出结构，支持复制与下载 .txt |
| **满分校验** | 不默认 100 分（综应常见 150、遴选可能 120），未填时标记「待考生确认」 |
| **阅卷标准库** | 考试范式库 / 题型专项规则 / 大作文五维权重可视化 |
| **历史记录** | localStorage 持久化，最多 30 条、新在前，支持载入 / 删除 / 清空 |

## 目录结构

```
.
├── index.html            入口：页头 / 范式提示条 / 输入区 / 输出区 / 抽屉 / Toast
├── assets/
│   ├── styles.css        全部样式（CSS 变量设计令牌，砚墨深色主题）
│   ├── data.js           数据层：考试范式 / 题型 / 字数规则 / 专项规则 / 输出结构 / 角色说明书
│   └── app.js            逻辑层：状态 / 字数统计 / 校验 / 指令组装 / 渲染 / 本地存储
├── .nojekyll             跳过 Jekyll 处理（GitHub Pages）
└── .gitignore
```

## 本地运行

直接用浏览器打开 `index.html` 即可。

如需要本地服务器：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 七段固定输出结构

① 总分与等级 ｜ ② 当前生效阅卷范式 ｜ ③ 得分点梳理 ｜ ④ 失分明细（扣分可溯源）｜ ⑤ 参考高分参考答案 ｜ ⑥ 逐句修改方案 ｜ ⑦ 针对性提升建议

## 说明

- 所有采分点要求 100% 来自用户提供的给定材料，严禁脱离材料凭空编造。
- 打分贴近真实考场，一类文 / 高分等级严格控制。
- 本工具生成的是**符合官方阅卷规则的结构化指令**，实际批改由使用者投喂的 AI 完成。
